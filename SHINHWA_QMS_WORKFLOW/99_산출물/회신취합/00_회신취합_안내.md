# 회신 취합 절차 (2026-10-08)

인쇄물을 직접 전달했고(2026-10-08), 회신 기한은 2026-10-15 입니다. 회신을 받은 뒤의 취합 절차입니다.

## 1. 회신 받기
- 담당자가 인쇄본의 ☐ 에 체크하고 메모·확인자를 적어 돌려줍니다.
- 종이 회신은 사람이 `발송용_최종_20261008/첨부_<담당자>_확인요청표.xlsx` 의 본인 시트에 옮겨 적습니다(확인 결과 드롭다운 선택, 메모, 확인자, 확인일). 담당자가 xlsx 로 직접 회신하면 그 파일을 씁니다.
- 채운 파일을 `회신취합/회신수집/` 에 넣습니다(파일 이름 그대로).

## 2. 취합 (사용하는 PC 에서)
```
cd SHINHWA_QMS_WORKFLOW/99_산출물/회신취합
python3 회신취합.py 회신수집            # 미리보기: 읽은 항목·담당자별 응답 건수·경고
python3 회신취합.py 회신수집 --apply    # 체크리스트 사본 + 반영 후보 CSV 생성
```
- 필요 패키지: openpyxl.
- **원본 체크리스트(`SQ_회신현황_체크리스트_20261008.xlsx`)는 수정하지 않습니다.** 새 파일 `SQ_회신현황_체크리스트_회신반영_YYYYMMDD[_vN].xlsx` 에 회신일·회신 내용 요약·확인자·회신 상태를 채웁니다(응답한 행 = 회신 완료, 응답한 담당자의 나머지 행 = 일부 회신).
- `회신반영후보_YYYYMMDD.csv`: 건별 회신 내용과 **반영 후보**(예: 통합 해제 후보, 현물 보유 반영 후보, 작성 파일 수령 → recheck)를 냅니다. 후보일 뿐이며 FM Master·증빙 매핑표·문서 상태는 자동으로 바꾸지 않습니다.
- 확인 결과가 비어 있으면 '미응답 — 재요청'으로 표시합니다. 체크리스트에 없는 SQ NO 는 경고로 알립니다.

## 3. 사람이 확정
반영 후보를 검토해 확정한 것만 증빙 매핑표(v3)·FM Master(새 파일)·결정 CSV 에 반영합니다. 확정 전에는 양식 번호·문서 상태를 바꾸지 않습니다.

## 4. 시험 결과
이광재 님 시트 일부를 채운 시험 파일로 미리보기·적용을 확인했습니다(시험 파일은 저장소에 넣지 않음). 실제 회신 파일 형식은 `발송용_최종_20261008/첨부_*.xlsx` 와 같아야 합니다.
