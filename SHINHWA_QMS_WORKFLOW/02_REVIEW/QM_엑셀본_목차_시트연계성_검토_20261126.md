## 4. 확인 필요
- 쪽 표기 `장-쪽`의 장 번호(7~17)와 목차 '장' 열(1~10)이 다름(예: 1.품질방침 = 7-1). 원본 xls 방식이며, 보는 사람이 혼동할 수 있어 설명 문구 추가 여부 결정 필요.
- `제3장 조직도`(03 조직도 시트)와 `3.용어` 장이 같은 '3장'으로 읽힐 수 있음.
- 개정현황 비고 '승인본'은 승인 후에만 유효(현재 미승인 초안). 03 조직도(26년) 시트는 목차 행 없음. SH-FM-001은 유효 후보 상태.
