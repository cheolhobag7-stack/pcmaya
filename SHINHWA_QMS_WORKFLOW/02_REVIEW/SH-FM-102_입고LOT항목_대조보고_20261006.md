# SH-FM-102 입고 LOT 항목 대조 보고 (읽기 전용 대조, 양식 수정 없음)

대상: `05_FINAL/RELEASED/SH-FM-101-121/Rev03/SH-FM-101-121_현장작성양식_Rev03_수정본.xlsx` (SH-FM-102, SH-FM-104)
기준: SH-QP-018 Rev.03 개정 초안 3.2·3.4·7.1 (입고 LOT·공급사 LOT 를 입고대장에 함께 기록 / 입고 LOT 일자=입고일 / 보존 3년·품질팀 서버)

## 결과: HOLD — SH-FM-102 에는 입고대장 항목이 없음
| 필요 항목 | SH-FM-102 (생산·검사·출하 LOT 이력) | SH-FM-104 (자재 입고·보관·불출 기록) |
|---|---|---|
| 입고 LOT(`L`+입고일 YYMMDD+순번) | 없음 | '자재 LOT' 열만 있음(입고 LOT 로 쓸 수 있으나 명시 없음) |
| 공급사 LOT | 없음(`원자재 품번 / 공급자` 칸, `원자재 LOT` 열만) | 없음 |
| 입고일 | 없음 | '일자' 열(수불 일자) |
| 입고수량·검사상태 | 없음 | 입고수량 있음, 검사상태 없음 |
| 생산 LOT↔원자재 LOT 연결 | 있음(생산일·완제품 LOT·원자재 LOT) | '불출처·사용 LOT' 열 |

- SH-FM-102 는 생산 LOT 연결 + 검사·출하 연결용이며 입고대장이 아님. 입고에 가까운 양식은 **SH-FM-104**(자재구매부서, 연계 SH-QP-018 포함)이나 공급사 LOT 열이 없음.
- 따라서 "입고 LOT·공급사 LOT 는 입고대장(SH-FM-102 포함)" 은 현 양식과 불일치. 선택지: ① 입고대장을 **SH-FM-104** 로 지정하고 공급사 LOT 열(및 검사상태) 추가 ② SH-FM-102 에 입고 LOT·공급사 LOT·입고일 열 추가 ③ 별도 입고대장 양식 신설(SH-FM 번호는 담당자 확정). 어느 쪽이든 양식 개정(Rev 처리)이 필요하며 임의 변경하지 않음.

## 추가 불일치 (QP-018 초안 vs 양식)
| 항목 | QP-018 초안 | SH-FM-102 / 104 / 전 양식 |
|---|---|---|
| 보존기간 | LOT 추적성 기록 3년 | 양식 하단·안내 모두 **5년**("보존기간은 전 양식 5년으로 확정") |
| 보관 위치 | 품질팀 서버 | 생산관리부서 기록철(102), 자재구매부서 기록철(104) |
| 일자 기산 | 생산일(입고 기록은 입고일) | 양식에 기산점 표기 없음 |
- 같은 LOT 이력 기록에 대해 절차서(3년)와 양식(5년)이 다르면 심사에서 부적합 소지. 선택지: 양식을 3년으로 맞춤(양식 개정) / 절차서를 5년으로 맞춤 / LOT 추적성 기록만 5년 등 구분 명시. 사용자 결정 필요.
- (참고) qms_rules 의 LOT 추적 규정값은 3년·1시간이며, 이번 FM Rev.03 은 사용자 지시로 5년 확정된 상태.
