## 결과: HOLD — SH-FM-102 에는 입고대장 항목이 없음
| 필요 항목 | SH-FM-102 (생산·검사·출하 LOT 이력) | SH-FM-104 (자재 입고·보관·불출 기록) |
|---|---|---|
| 입고 LOT(`L`+입고일 YYMMDD+순번) | 없음 | '자재 LOT' 열만 있음(입고 LOT 로 쓸 수 있으나 명시 없음) |
| 공급사 LOT | 없음(`원자재 품번 / 공급자` 칸, `원자재 LOT` 열만) | 없음 |
| 입고일 | 없음 | '일자' 열(수불 일자) |
| 입고수량·검사상태 | 없음 | 입고수량 있음, 검사상태 없음 |
| 생산 LOT↔원자재 LOT 연결 | 있음(생산일·완제품 LOT·원자재 LOT) | '불출처·사용 LOT' 열 |

- SH-FM-102 는 생산 LOT 연결 + 검사·출하 연결용이며 입고대장이 아님. 입고에 가까운 양식은 **SH-FM-104**(자재구매부서, 연계 SH-QP-018 포함)이나 공급사 LOT 열이 없음.
- 따라서 "입고 LOT·공급사 LOT 는 입고대장(SH-FM-102 포함)" 은 현 양식과 불일치. 선택지: ① 입고대장을 **SH-FM-104** 로 지정하고 공급사 LOT 열(및 검사상태) 추가 ② SH-FM-102 에 입고 LOT·공급사 LOT·입고일 열 추가 ③ 별도 입고대장 양식 신설(SH-FM 번호는 담당자 확정). 어느 쪽이든 양식 개정(Rev 처리)이 필요하며 임의 변경하지 않음.
