# SH-QP-002 문서화된 정보 관리 절차서 — 문서번호 규칙 추가 문구 (초안, 미적용·미승인)

대상: `SH_QMS_통합문서_Rev03_20260929_수정본4.docx` 의 SH-QP-002 **4. 문서 작성 및 번호부여** (통합문서·릴리스본은 수정하지 않음, 제안만).
작성 근거: 품질경영매뉴얼 3.2 문서 계층·부록 F, FM Master(통합20), 문서관리대장(수정본8), 이 프로젝트에서 사용자가 확정한 운영 사항. `[확인 필요]` 표시는 담당자가 확정해야 할 값이며 임의로 채우지 않았다.

## 1. 현행 문구 (4절)
- 문서번호, 문서명, 개정번호, 시행일, 작성·검토·승인 정보를 표시한다.
- 문서번호는 **승인된 문서번호 체계에 따라 중복 없이 부여한다.**  ← 체계 자체는 문서에 정의돼 있지 않음
- 작업현장 문서는 작업자가 이해할 수 있고 필요한 정보가 명확하도록 작성한다.

## 2. 변경안 (4절 확장: 4.1~4.4 추가, 현행 3개 항목은 유지)

**4.1 문서번호 체계**
문서번호는 `SH-<구분>-<3자리 일련번호>` 형식으로 부여한다.

| 구분 | 문서 | 번호 형식 | 현행 범위 |
|---|---|---|---|
| QM | 품질경영매뉴얼 | SH-QM-NNN | SH-QM-001 |
| QP | 절차서 | SH-QP-NNN | SH-QP-001~025 |
| WI | 작업표준서 | SH-WI-NNN | SH-WI-001~030 |
| FM | 기록양식 | SH-FM-NNN | SH-FM-001~364 (이후 순번 부여) |

개정번호는 `Rev.NN`으로 표시한다. 외부출처 문서(도면·CSR·법규·외부표준)는 발행처의 문서번호를 그대로 사용하며 회사 문서번호를 부여하지 않고 외부문서 목록으로 관리한다.

**4.2 번호 부여 절차**
① 신규 문서 작성자는 문서 제·개정 신청에 문서 구분과 명칭을 기재하여 문서관리 책임자[확인 필요: 채번 담당 직책]에게 번호를 요청한다.
② 문서관리 책임자는 문서 마스터리스트(문서관리대장·FM Master)에서 동일·유사 명칭의 문서가 이미 있는지 확인한 후 다음 순번을 부여하고 마스터리스트에 등록한다.
③ 동일하거나 같은 용도의 문서가 이미 있으면 신규 번호를 부여하지 않고 기존 번호를 사용하거나 통합한다.
④ 번호는 승인 전에 부여할 수 있으나, 승인되지 않은 문서는 배포본으로 사용하지 않으며 마스터리스트에 승인 상태를 구분하여 표시한다.

**4.3 번호 관리 원칙**
- 부여한 번호는 재사용하거나 삭제하지 않는다. 문서를 통합·폐기하는 경우 번호는 '사용 안 함'으로 표시하고 대표 번호 또는 폐기 사유를 마스터리스트에 남긴다.
- 같은 명칭의 문서는 하나의 번호로 관리한다. 번역본은 원본 문서 번호에 언어 표기를 붙여 관리한다.
- 개정 시 문서번호는 바꾸지 않고 개정번호를 올리거나 재개정 사유를 개정이력에 기록한다. 이전 개정본은 보관하고 구본은 회수·표시한다.
- 문서번호, 개정번호, 시행일, 승인 정보는 승인된 사실만 마스터리스트에 기록하며 확정 전 값을 임의로 기입하지 않는다.
- 양식 파일은 `<문서번호>_<문서명>_Rev<NN>` 형식의 이름을 사용하고, 여러 번호를 한 파일로 묶는 경우 범위 안의 모든 번호가 포함되어야 한다.

**4.4 번호 체계 변경**
번호 형식·범위 또는 구분 코드를 변경하는 경우 문서 제·개정 신청에 따라 QP-002 개정과 함께 승인하고 마스터리스트와 관련 문서의 참조를 일괄 갱신한다.

## 3. 함께 정리할 사항 (제안)
1. **SH 접두어 없는 참조**: 같은 QP-002 8절에 `FM-QMS-N13 도면일치성관리기준서` 가 있다(회사 번호 체계 아님, `crosscheck` 에서 HOLD 대상). 실제 번호(SH-FM-NNN)로 정정할지 확인 필요.
2. **문서관리 책임자 직책 표기**: QM 7.5 에 '문서관리 책임자' 가 쓰이나 QP-002 표(작성 품질경영 담당·검토 품질책임자)와 일치하는 직책명 확인 필요.
3. **개정 방식**: QP-002 Rev.03 유지(내용 개정) 또는 Rev 상승 — 결정 필요. 승인 후 문서관리대장 `02_개정이력`·`06_Rev03_반영이력`에 반영.
4. 적용 방법: 승인 의사 확정 후 통합문서 새 `_수정본N` 에 QP-002 4절만 반영(구간 밖 변경 없음 확인), 낱개 `SH-QP-002` 발췌본도 함께 갱신.
