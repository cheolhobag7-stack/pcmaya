## 1. 목적
(Rev.03 유지) 원자재 입고부터 생산, 검사, 보관 및 출하까지 제품 상태와 LOT 이력을 식별하여 이상 발생 시 영향범위를 신속하고 정확하게 추적할 수 있도록 규정한다.

## 2. 식별 대상
(Rev.03 표 유지: 입고·공정·검사·완제품·출하)

## 3. LOT 번호 체계 [변경]
3.1 LOT 번호는 **현재 사용 중인 기존 체계를 유지**한다. 코드체계 전환(LEGACY→NEW)은 이번 개정에 적용하지 않으며 전환일·코드 대응표는 정하지 않는다. (9/21본의 LEGACY/NEW 구분 조항은 향후 전환 시를 위한 참고로만 둔다.)
3.2 기존 LOT 번호 형식(사용자 확인 2026-10-06): `L` + 생산일(YYMMDD, 6자리) + `-` + 일별 순번(4자리). 예) `L260817-0019` = 2026-08-17 생산분 19번째. 입고·공정·완제품 LOT 모두 동일한 형식을 사용한다(사용자 확인 2026-10-06). 일자(YYMMDD)는 공정·완제품 LOT 는 생산일, **입고 LOT 는 입고일**을 기준으로 한다(사용자 확인 2026-10-06). 입고 LOT 와 공급사 LOT 는 입고대장에 함께 기록하여 연결한다(3.4, 사용자 확인 2026-10-06).
3.3 내부 추적 식별키는 품번, 실제 생산일(YYYY-MM-DD) 및 LOT(배치) 번호의 조합으로 관리하며, 보존기간 동안 서로 다른 이력이 동일 식별키로 조회되지 않도록 한다. 고객 라벨 표기와 내부 식별키는 연결대장으로 상호 조회한다.
3.4 공급사 LOT 는 입고 시 입고 LOT 와 함께 **입고대장에 기록**하여 연결한다(입고대장은 **SH-FM-104 자재 입고·보관·불출 기록**으로 한다, 사용자 확정 2026-10-06; 양식 개정 초안 `03_EDIT/AUTO_DRAFT/SH-FM-101-121_현장작성양식_Rev03_LOT정합_DRAFT.xlsx`). 바코드 훼손·송장 불일치·오기 시 공급사 LOT 를 임의 추정·대체하지 않고 '미확인', 검사상태 '보류'로 관리하며 즉시 격리한다.

## 4. 추적성 수준
(Rev.03 유지) 고객, 법규, 제품안전 및 리스크 요구에 따라 추적성 단위를 정한다. 제품안전 또는 고객 지정 특성의 경우 강화된 추적성과 기록 보존을 적용한다.

## 5. 추적성 시험 [변경]
5.1 분기 1회(5.3) 특정 출하 LOT 를 선정하여 완제품에서 원자재/공정/검사 이력으로 역추적하고, 특정 원자재 LOT 에서 사용 제품과 출하처를 순추적한다.
5.2 **추적 목표시간은 입고부터 출하까지 전 구간(입고→공정→검사→보관→출하)에 대해 1시간(60분)** 이내로 한다(사용자 확인 2026-10-06). 소요시간과 누락정보를 평가하여 초과·누락 시 원인 분석과 개선을 수행한다. 소요시간은 **추적 요청 시각부터 결과 확인 시각까지**로 측정한다(사용자 확인 2026-10-06).
5.3 추적성 시험은 **분기 1회** 실시하며, 시험마다 **순추적(원자재 LOT→사용 제품·출하처) 1건, 역추적(출하 LOT→완제품·공정·검사·원자재 이력) 1건**을 선정한다(사용자 확인 2026-10-06). 제품안전·고객 지정 특성 제품 우선 선정 여부 등 세부 선정 기준: [확인 필요]
