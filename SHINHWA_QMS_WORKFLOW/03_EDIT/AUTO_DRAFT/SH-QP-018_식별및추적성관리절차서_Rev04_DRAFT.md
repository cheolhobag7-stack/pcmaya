## 1. 목적 및 적용범위
1.1 목적: 원자재 입고부터 생산, 검사, 보관 및 출하까지 제품 상태와 LOT 이력을 식별하여 이상 발생 시 영향범위를 신속하고 정확하게 추적할 수 있도록 규정한다.
1.2 적용범위: 전 부서의 현장 기록에 적용한다. 입고·공정·검사·보관·출하 단계의 LOT 식별, 추적성 시험, 현장 기록의 스캔·서버 저장·보존·백업을 포함한다.

## 2. 식별 대상
| 단계 | 식별정보 예 |
|---|---|
| 입고 | 공급자, 원자재/부품 LOT, 입고일, 검사상태 |
| 공정 | 품번, 생산일, 교대, 설비/금형, 공정 LOT |
| 검사 | 검사상태, 검사자, 계측기, 결과 |
| 완제품 | 품번, LOT, 수량, 합격상태 |
| 출하 | 고객, 출하일, 출하 LOT, 수량, 라벨/납품정보 |

## 3. LOT 번호 체계
3.1 LOT 번호는 현재 사용 중인 기존 체계를 유지한다. 코드체계 전환(LEGACY/NEW)은 적용하지 않으며, 향후 전환이 필요하면 별도로 승인된 전환일과 코드 대응표를 따른다.
3.2 LOT 번호 형식은 영문 L + 일자(YYMMDD, 6자리) + 하이픈(-) + 일별 순번(4자리)으로 한다. 예) L260817-0019 = 2026-08-17 일자의 19번째. 입고·공정·완제품 LOT 모두 같은 형식을 사용하며, 일자는 공정·완제품 LOT 는 생산일, 입고 LOT 는 입고일을 기준으로 한다.
3.3 내부 추적 식별키는 품번, 실제 생산일(YYYY-MM-DD) 및 LOT(배치) 번호의 조합으로 관리하며, 보존기간 동안 서로 다른 이력이 동일 식별키로 조회되지 않도록 한다. 고객 라벨 표기와 내부 식별키는 연결대장으로 상호 조회한다.
3.4 공급자 LOT 는 입고 시 입고 LOT 와 함께 입고대장(SH-FM-104 자재 입고·보관·불출 기록)에 기록하여 연결한다. 바코드 훼손·송장 불일치·오기 시 공급자 LOT 를 임의로 추정하거나 대체하지 않고 '미확인', 검사상태 '보류'로 관리하며 즉시 격리한다.

## 4. 추적성 수준
고객, 법규, 제품안전 및 리스크 요구에 따라 추적성 단위를 정한다. 제품안전 또는 고객 지정 특성의 경우 강화된 추적성과 기록 보존을 적용한다.

## 5. 추적성 시험
5.1 추적성 시험은 분기 1회 실시하며, 시험마다 순추적 1건과 역추적 1건을 선정한다. 역추적은 출하 LOT 에서 완제품·공정·검사·원자재 이력으로, 순추적은 원자재 LOT 에서 사용 제품과 출하처로 확인한다.
5.2 추적 목표시간은 입고부터 출하까지 전 구간(입고→공정→검사→보관→출하)에 대해 1시간(60분) 이내로 하며, 추적 요청 시각부터 결과 확인 시각까지로 측정한다. 소요시간과 누락정보를 평가하여 초과·누락 시 원인 분석과 개선을 수행한다.
5.3 시험 기록은 기존 추적성 모의시험 기록(End-to-End Traceability 기록) 양식을 사용한다. 시험 대상 LOT 의 세부 선정 기준은 별도로 두지 않는다.

## 6. 식별 이상
- 라벨 분실·혼입 시 즉시 보류 및 영향범위 격리
- LOT 연결이 불가능한 제품은 적합성 확인 전 출하 금지
- 재작업·특채품도 원 LOT와 처리이력을 유지
- 고객 라벨 요구와 바코드/EDI 요구를 준수
- 라벨 재발행은 원기록과 실물 대조로 동일성이 입증된 경우에만 하고, 입증되지 않으면 재발행하지 않고 보류
- 생산 중 불량·오사용은 불량 수량을 분리하고 기존 LOT 연결을 유지하며, 영향 범위·수량·소재지 조사 후 처리 근거를 기록

## 7. 관련 기록 및 보존
| 기록 | 예 | 보존기간 |
|---|---|---|
| 입고/원자재 LOT 기록 | 공급자 LOT 연계 | 3년 |
| 생산일보 | 공정 LOT/설비/교대 | 3년 |
| 검사기록 | 검사결과/계측기 | 3년 |
| 출하이력 | 고객/LOT/수량 | 3년 |
| 추적성 모의시험 | 순·역추적 결과 | 3년 |
7.1 LOT 추적성 기록의 보존기간은 3년(36개월)으로 한다. 기산점은 생산일(입고 기록은 입고일), 보관 위치는 품질팀 서버로 하며, 보존기간이 지난 기록의 폐기 권한은 품질책임자에게 있다.
7.2 고객 요구 또는 법규가 더 긴 보존을 요구하는 기록은 그 기간을 따른다. 해당 여부는 품질부서가 확인한다.
7.3 보존기간 중인 기록은 임의로 폐기하지 않는다.
7.4 현장 기록의 제출·스캔·서버 저장·백업
7.4.1 서버 접근권한: 읽기는 품질팀과 현장 부서 모두 가능하다. 수정·삭제를 포함한 쓰기는 품질팀만 가능하다. 자재출하팀은 저장(업로드) 전용 권한만 가지며 저장한 파일을 수정·삭제할 수 없다.
7.4.2 제출과 스캔: 기록 작성 부서는 작성한 기록을 작성 후 1일(달력일) 이내에 종이로 자재출하팀에 제출한다. 자재출하팀은 작성 후 3일(달력일, 주말·공휴일 포함) 이내에 스캔하여 서버에 저장한다. 따라서 작성 후 최대 4일 안에 스캔과 서버 저장이 끝난다.
7.4.3 종이 원본 인계·보관: 자재출하팀은 스캔 후 3일(달력일) 이내에 종이 원본을 품질팀에 인계하고 인계대장에 서명하여 확인한다. 품질팀은 종이 원본을 품질팀 사무실 캐비닛에 3년(서버 파일과 동일, 기산점은 7.1) 보관한다. 인계대장은 SH-FM-363 양식으로 한다.
7.4.4 스캔 결과 확인: 품질팀은 인수 시 스캔 파일을 종이 원본과 대조하여 확인하고, 결과(일치/불일치)를 인계대장 '품질팀 인수 확인'란에 기록한다.
7.4.5 불일치 시 재스캔과 보류: 불일치 또는 판독 불가 시 자재출하팀은 품질팀이 불일치를 통보한 날부터 3일(달력일) 이내에 재스캔하고, 재스캔 결과도 같은 방식으로 원본과 대조한다. 원본과 일치가 확인될 때까지 해당 기록은 '보류'로 관리하며, 보류 표시와 보류 해제는 인계대장 '조치·비고'란에 기록한다. 보류 중인 기록은 추적성 시험과 고객 제공에 사용하지 않는다.
7.4.6 긴급 추적: 고객 클레임, 리콜, 제품안전에 해당하는 경우 긴급 추적 여부의 판단과 종이 원본 활용의 승인은 품질책임자가 한다. 긴급 추적 시에는 품질팀이 보관 중인 종이 원본을 활용할 수 있으며, 품질책임자의 승인은 인계대장 '조치·비고'란에 일자와 서명으로 기록한다.
7.4.7 재스캔 파일과 불일치 파일: 재스캔 파일은 기존 파일을 덮어쓰지 않고 기존 파일명 뒤에 재스캔 순번(_재스캔1, _재스캔2 …)을 붙인 새 이름으로 저장한다. 예) 기록번호_스캔.pdf → 기록번호_스캔_재스캔1.pdf. 불일치였던 기존 파일은 삭제하지 않고 품질팀이 서버의 별도 폴더 '불일치보관'에 3년(기산점은 7.1) 보관한다.
7.4.8 백업: 서버는 매일 1회 자동으로 백업하고, 백업은 서버와 분리된 별도 장비에 30일 보관한다. 보존기간 3년의 기록 자체는 서버에 보존하며 백업은 복구용이다. 별도 장비는 사내서버로 한다.
7.4.9 복구 점검: 품질팀 담당자가 월 1회 백업의 복구를 점검한다. 매달 서버 전체('불일치보관' 폴더 포함)에서 스프레드시트 난수 함수로 3건을 무작위 선정하여 백업에서 복원하고 열람·내용 확인이 되는지 본다. 점검 결과는 선정에 사용한 난수 값과 함께 복구 점검 기록(SH-FM-364 양식, 보존기간 3년)에 기록한다. 점검 담당자는 김주태 이사, 대체자는 이광재 부장으로 한다.
7.4.10 백업 실패: 백업이 실패하면 품질팀 담당자에게 메일로 알리고(수신 메일 주소: sinhwa_ht@sinhwaht.co.kr), 실패를 안 날의 다음날(달력일)까지 재실행한다. 기한 안에 재실행이 불가능하면 불가를 확인한 당일 안에 품질책임자에게 메일로 보고한다. 백업 실패·재실행·보고 내용은 복구 점검 기록의 '백업 실패 기록'란에 함께 기록한다.
