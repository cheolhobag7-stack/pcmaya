## 1. 목적
(Rev.03 유지) 원자재 입고부터 생산, 검사, 보관 및 출하까지 제품 상태와 LOT 이력을 식별하여 이상 발생 시 영향범위를 신속하고 정확하게 추적할 수 있도록 규정한다.

## 2. 식별 대상
(Rev.03 표 유지: 입고·공정·검사·완제품·출하)

## 3. LOT 번호 체계 [변경]
3.1 LOT 번호는 **현재 사용 중인 기존 체계를 유지**한다. 코드체계 전환(LEGACY→NEW)은 이번 개정에 적용하지 않으며 전환일·코드 대응표는 정하지 않는다. (9/21본의 LEGACY/NEW 구분 조항은 향후 전환 시를 위한 참고로만 둔다.)
3.2 기존 LOT 번호 형식(사용자 확인 2026-10-06): `L` + 생산일(YYMMDD, 6자리) + `-` + 일별 순번(4자리). 예) `L260817-0019` = 2026-08-17 생산분 19번째. 입고·공정·완제품 LOT 모두 동일한 형식을 사용한다(사용자 확인 2026-10-06). 일자(YYMMDD)는 공정·완제품 LOT 는 생산일, **입고 LOT 는 입고일**을 기준으로 한다(사용자 확인 2026-10-06). 입고 LOT 와 공급사 LOT 는 입고대장에 함께 기록하여 연결한다(3.4, 사용자 확인 2026-10-06).
3.3 내부 추적 식별키는 품번, 실제 생산일(YYYY-MM-DD) 및 LOT(배치) 번호의 조합으로 관리하며, 보존기간 동안 서로 다른 이력이 동일 식별키로 조회되지 않도록 한다. 고객 라벨 표기와 내부 식별키는 연결대장으로 상호 조회한다.
3.4 공급사 LOT 는 입고 시 입고 LOT 와 함께 **입고대장에 기록**하여 연결한다(입고대장은 **SH-FM-104 자재 입고·보관·불출 기록**으로 한다, 사용자 확정 2026-10-06; 양식 개정 초안 `03_EDIT/AUTO_DRAFT/SH-FM-101-121_현장작성양식_Rev03_LOT정합_DRAFT.xlsx`). 바코드 훼손·송장 불일치·오기 시 공급사 LOT 를 임의 추정·대체하지 않고 '미확인', 검사상태 '보류'로 관리하며 즉시 격리한다.

## 4. 추적성 수준
(Rev.03 유지) 고객, 법규, 제품안전 및 리스크 요구에 따라 추적성 단위를 정한다. 제품안전 또는 고객 지정 특성의 경우 강화된 추적성과 기록 보존을 적용한다.

## 5. 추적성 시험 [변경]
5.1 분기 1회(5.3) 특정 출하 LOT 를 선정하여 완제품에서 원자재/공정/검사 이력으로 역추적하고, 특정 원자재 LOT 에서 사용 제품과 출하처를 순추적한다.
5.2 **추적 목표시간은 입고부터 출하까지 전 구간(입고→공정→검사→보관→출하)에 대해 1시간(60분)** 이내로 한다(사용자 확인 2026-10-06). 소요시간과 누락정보를 평가하여 초과·누락 시 원인 분석과 개선을 수행한다. 소요시간은 **추적 요청 시각부터 결과 확인 시각까지**로 측정한다(사용자 확인 2026-10-06).
5.3 추적성 시험은 **분기 1회** 실시하며, 시험마다 **순추적(원자재 LOT→사용 제품·출하처) 1건, 역추적(출하 LOT→완제품·공정·검사·원자재 이력) 1건**을 선정한다(사용자 확인 2026-10-06). 제품안전·고객 지정 특성 제품 우선 선정 여부 등 세부 선정 기준: [확인 필요]

[변경] 라벨 재발행은 원기록과 실물 대조로 동일성이 입증된 경우에만 하고, 입증 불가 시 재발행하지 않고 보류한다. 생산 중 불량·오사용은 불량 수량을 분리하고 기존 LOT 연결을 유지하며 영향 범위·수량·소재지 조사 후 처리 근거를 기록한다.

7.2 고객 요구 또는 법규가 더 긴 보존을 요구하는 기록은 그 기간을 따른다(해당 여부 품질부서 확인).
7.3 보존기간 중 기록은 임의 폐기하지 않는다.
7.4 [변경] 품질팀 서버의 접근권한(사용자 확인 2026-10-06): ① **읽기는 품질팀과 현장 부서 모두 가능**하다. ② **수정·삭제를 포함한 쓰기는 품질팀만 가능**하다. ③ 현장 기록은 **자재출하팀이 스캔하여 서버에 저장**하며, 자재출하팀은 **저장(업로드) 전용 권한**만 가지고 저장한 파일의 수정·삭제는 할 수 없다. **스캔 기한은 작성 후 3일(달력일, 주말·공휴일 포함) 이내**(사용자 확인 2026-10-06), **종이 원본은 스캔 후 품질팀에 인계하여 품질팀이 보관**한다(사용자 확인 2026-10-06; **인계 기한은 스캔 후 3일(달력일) 이내**이며, **종이 원본의 보관 기간은 3년**(서버 파일과 동일, 기산점은 7.1)으로 한다(사용자 확인 2026-10-06). **종이 원본 보관 장소는 품질팀 사무실 캐비닛**으로 한다. **인계는 인계대장에 서명하여 확인**한다(사용자 확인 2026-10-06). 인계대장은 **SH-FM 신규 양식**으로 하며(사용자 결정 2026-10-06) 초안은 `03_EDIT/AUTO_DRAFT/SH-FM-[번호미정]_기록인계대장_초안.xlsx`이다. 양식 번호: [확인 필요 — 담당자 확정 전 임의 부여 금지] 품질팀은 인수 시 **스캔 파일을 종이 원본과 대조하여 확인**하고 결과(일치/불일치)를 인계대장 '품질팀 인수 확인'란에 기록한다(사용자 확인 2026-10-06). 불일치·판독 불가 시 **자재출하팀은 3일(달력일) 이내 재스캔**한다(사용자 확인 2026-10-06; 3일의 기산일은 불일치 통보일로 가정, 확인 필요). 재스캔 결과도 같은 방식으로 원본과 대조하고, **재스캔이 완료되어 원본과 일치가 확인될 때까지 해당 기록은 '보류'로 관리**한다(사용자 확인 2026-10-06; 보류 표시는 **인계대장의 '조치·비고'란에 기록**하고 재스캔 후 일치가 확인되면 같은 란에 보류 해제를 기록한다(사용자 확인 2026-10-06); **보류 중인 기록은 추적성 시험과 고객 제공에 사용하지 않는다**(사용자 확인 2026-10-06). 다만 **긴급 추적 시에는 품질팀이 보관 중인 종이 원본을 활용할 수 있다**(사용자 확인 2026-10-06; 긴급 추적 여부의 **판단과 원본 활용의 승인은 품질책임자**가 한다(사용자 확인 2026-10-06); **긴급 추적의 범위는 고객 클레임, 리콜, 제품안전**으로 한다(사용자 확인 2026-10-06). 품질책임자의 **활용 승인은 인계대장 '조치·비고'란에 일자와 서명으로 기록**한다(사용자 확인 2026-10-06).)). 기존 파일 처리(저장 전용 권한이라 덮어쓰기 불가): [확인 필요]), 품질팀 스캔 결과 확인 절차, 백업 방법·주기: [확인 필요]
