# MCP_CONNECTOR_PLAN

| 우선순위 | 연결 | 주요 용도 | 초기 권한 |
|---|---|---|---|
| 1 | Google Drive/문서저장소 | QMS 승인본, 문서관리대장, 심사자료 | READ |
| 2 | Gmail/메일 | 고객사 요청, 클레임, 심사요청 확인 | READ |
| 3 | Google Calendar | 심사/회의/완료기한 확인 | READ |
| 4 | Notion/업무관리 | Action Item 관리 | READ/CREATE |
| 5 | GitHub | 자동화 코드 버전관리 | READ/CREATE |

실제 서버 등록 정보는 해당 MCP 공급자의 공식 설치 정보를 사용한다.
검증되지 않은 MCP URL이나 패키지명을 임의로 사용하지 않는다.
